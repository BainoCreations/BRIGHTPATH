## Image recommendations
- Use JPG for photographs, except the included PNG hero image.
- Use high-quality landscape images. For wide hero imagery, use 16:9 or wider; for cards and category sections, use images at least 1200 pixels wide where possible.
- Use authentic Brightpath photos or images you have permission to use.
- Do not rename files to `.jpg` unless the actual image file is encoded as JPEG.
- Images are referenced with relative paths, so the site will work on GitHub Pages when the folder structure is preserved.
