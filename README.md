# Brightpath Uniform Supplies website

A complete, responsive multi-page static website for Brightpath Uniform Supplies, including the supplied logo and product photographs.

## Pages
- `index.html` — homepage and product overview
- `about.html` — company introduction
- `products.html` — uniforms, workwear, stationery and general supplies
- `services.html` — sourcing and quotation support
- `gallery.html` — supplied product photographs
- `contact.html` — phone, email and WhatsApp contact links
- `quote.html` — enquiry form that prepares an email addressed to `info@brightpathsupplies.co.ke`

## Images and assets
All images are stored in `assets/images/`. The supplied Brightpath logo and uniform photographs are included. A stationery illustration is included because the supplied photographs do not show stationery products. No image renaming or editing is required.

## Publish on GitHub Pages
1. Download and extract this ZIP.
2. Upload the contents of the `brightpath-uniforms-website` folder into the root of your GitHub repository, preserving the `assets` folder.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose your main branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish and open the URL shown on that page.

## Important note about enquiries
This is a static website, so it does not require a server. When a visitor submits the quotation form, it opens the visitor's default email application with the enquiry prefilled; the visitor must press **Send**. If their device has no email app configured, they can use the WhatsApp link or email the company directly. The website does not silently store form submissions.

Only contact information supplied by the company has been included. No unconfirmed street address, opening hours, certifications or company claims have been invented.
